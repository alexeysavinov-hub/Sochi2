BIOSOMA Mountain Retreat — сайт

1. Загрузите всё содержимое этой папки по FTP в корень сайта (или в подпапку).
2. Откройте адрес сайта — index.html откроет главную страницу.
3. Документы (оферта, правила отмены, политика, согласие) — docs.html.

Страницы нужно открывать через веб-сервер (http/https), а не двойным щелчком по файлу.
Шрифт Onest подключается с Google Fonts.
Форма бронирования — прототип: запросы пока никуда не отправляются, нужен обработчик на сервере.
Тексты документов — шаблоны: перед публикацией заполните реквизиты в [квадратных скобках] и согласуйте с юристом.
