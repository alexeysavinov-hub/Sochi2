BIOSOMA Mountain Retreat — сайт для загрузки по FTP

ЗАГРУЗКА
1. Загрузите всё содержимое папки (включая скрытый файл .htaccess) в корень сайта.
2. Нужен хостинг с PHP 7.4+ и cURL. Открывать страницы — только через http/https.

НАСТРОЙКА ПЕРЕД ЗАПУСКОМ
1. config.php — e-mail для заявок, Telegram-бот (токен и chat_id), ключи ЮKassa, цены программ.
2. Замените example.ru на ваш домен: index.html, docs.html, robots.txt, sitemap.xml, config.php.
3. Цены и состав программ в блоке «Цены и даты» — примерные, проверьте и пришлите актуальные.
4. Контакты-заглушки: +7 (000) 000-00-00, booking@[домен], ссылки Telegram/WhatsApp — замените.
5. Документы (docs.html): заполните реквизиты в [квадратных скобках] и согласуйте с юристом.

ФОТО
Все изображения в img/biosoma/ сгенерированы для презентации — перед запуском замените реальной съёмкой, сохранив имена файлов.
Фото и имена команды вымышленные — замените реальными сотрудниками.

КАК РАБОТАЕТ ФОРМА
Заявка уходит в send.php → письмо на mail_to и/или сообщение в Telegram.
После отправки гость может сразу внести предоплату 30% (pay.php → ЮKassa), если ключи ЮKassa заполнены.
